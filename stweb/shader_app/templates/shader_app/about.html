About Shadertree

Shadertree is a project by Evan Fletcher and Charles Lohr.

This server controls a 3D-scanned LED tree, set up on 15F. The 3D positions of each LED are taken as inputs to vertex shaders written on this site, which animate the LEDs on the tree.

Anyone can contribute a shader! Just click the "new" button at the top of the page. Anything that works in the editor should also work on the tree.

How does it work?

The tree itself is made out of about 5200 addressible LEDs, a custom board to drive them, and a Steam Deck, which controls the LEDs and also hosts this site.

During setup, the LEDs are programmed to blink out unique error correcting-codes, used to identify each LED in a video of the tree. The tree is "scanned" by walking around it with a camera, using a reconstruction method vaguely similar to Bundler (Snavely et al, 2006). The result is a tree where every LED's 3D coordinates are known.

These points are used as inputs for vertex shaders running on the Steam Deck. We use transform feedback to pull out LED colors every frame, then send these over USB to the micocontroller driving the LEDs.

In this website's editor, your shader is compiled and displayed with WebGL, but is otherwise run exactly as it will be on the real tree.
