Tips:

Perf and VSync: There is no vsync or display rate to miss - LEDs update when your shader is done, up to about 140Hz.

LED 3D Coordinates: Use iPos for volumetric-sampled effects. In the tree's coordinate system: +y up; (0,-1,0) is near the bottom center of the tree; (0,1,0) is near the top of the tree.

LED Index: The zero-indexed position of each LED in the string is also available (iIdx). Use this if you want to light up a specific LED.

The Tree is Real: Regrettably, the predefined vertex shader outputs gl_Position, gl_PointSize, and gl_ClipDistance do not work IRL, and will not affect the real tree. Sorry!

Shader prefix / inputs & outputs:
#version 300 es
in vec3 iPos;    // Input: LED 3D coordinate (+Y up; bottom center @ 0,-1,0; tip @ 0,1,0)
in uint iIdx;    // Index of LED in string. These are raw LED addresses and aren't contiguous. 
in float iTime;  // Input: Shader playback time (in seconds)
in int iFrame;   // Input: Frame counter

out vec3 outColor;    // Output: RGB color
